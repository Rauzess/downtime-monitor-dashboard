# 🟢 Downtime Monitor Dashboard

Um dashboard em tempo real construído para visualizar a estabilidade da rede, consumindo dados diretamente de um banco de dados Firebase. 

**Status do Projeto:** ⚠️ *O bot em Python responsável por fazer o ping e enviar os logs para o Firebase foi desligado temporariamente a pedido da equipe de infraestrutura.* A interface web segue funcional para visualização de dados históricos.

### 🛠️ Tecnologias
* HTML, CSS, JavaScript
* Firebase (Realtime Database)
* Python (Bot de coleta - Offline)
